Perché alcune lingue “costano” più token

Il vocabolario di un tokenizer BPE si costruisce partendo dai singoli byte e unendo, uno dopo l’altro, le coppie che compaiono più spesso nei testi di addestramento. Se quei testi sono in gran parte in inglese, le parole inglesi diventano token interi, mentre le altre lingue restano spezzate in pezzi più piccoli: la stessa informazione richiede più token.

Più token significano meno testo nella context window del modello, risposte più lente e, con le API cloud che fatturano a token, un costo maggiore. I vocabolari più recenti e più grandi riducono il divario: confronta cl100k_base (GPT-4, 100 mila token) con o200k_base (GPT-4o, 200 mila token).
